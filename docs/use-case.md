# Smart Dorm – Use Case сипаттамалары

## US-01 – Жүйеге кіру (авторизация)

Пайдаланушы Smart Dorm жүйесіне жеке логин және құпиясөз арқылы кіреді.

Негізгі қадамдар:
- пайдаланушы логин енгізеді;
- құпиясөз енгізеді;
- жүйе енгізілген мәліметтерді тексереді;
- пайдаланушының рөлі анықталады;
- рөліне сәйкес жеке кабинет ашылады.

Қатысушылар:
- Студент;
- Қабат старостасы;
- Комендант;
- Техникалық қызметкер;
- Программист.

## US-02 – Ақпаратты іздеу

Пайдаланушы Smart Dorm жүйесінен қажетті ақпаратты іздей алады.

Негізгі қадамдар:
- іздеу сұрауын енгізу;
- кілт сөз арқылы іздеу;
- фильтрлерді қолдану;
- іздеу нәтижелерін қарау;
- толық ақпаратты көру;
- қажет болған жағдайда нәтижені жүктеу.

Қатысушылар:
- Студент;
- Қабат старостасы;
- Комендант;
- Техникалық қызметкер.

## US-03 – Жөндеу өтінімін жасау

Студент немесе қабат старостасы жатақханадағы ақау туралы жөндеу өтінімін жасай алады.

Негізгі қадамдар:
- ақау түрін таңдау;
- ақаудың сипаттамасын жазу;
- фото немесе видео қосу;
- орналасқан орнын көрсету;
- жөндеу өтінімін жіберу.

Өтінім ақау түріне байланысты сантехникке, электрикке немесе плотникке бағытталады.

Техникалық қызметкер өтінімді көріп, жұмыс статусын жаңартады және жөндеу аяқталғаннан кейін нәтижесін енгізеді.

Қатысушылар:
- Студент;
- Қабат старостасы;
- Сантехник;
- Электрик;
- Плотник;
- Комендант;
- Программист.
